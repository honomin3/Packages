# Changelog

## 1.0.0 — unreleased source candidate

- Declare uniform or XYZ hierarchy scale on body bones and synchronize missing scale contributions to independent outfit rigs.
- Integrate with Modular Avatar Merge Armature, Bone Proxy and Scale Adjuster through public APIs.
- Correct scale animation on build clones while preserving original transforms, meshes and animation clips.
- Provide NDMF shared preview, automatic Prefab Mode preview and a processed-avatar inspection window.
- Support explicit migration of existing Scene instance scale with Undo/Redo and Prefab overrides.
- Summarize repeated Inspector warnings by reason and count, with expandable messages and related objects.
- Report unsupported nonuniform, shear, ambiguous mapping and placement cases; retain advanced-scale warnings.
- Require Modular Avatar 1.19.1 and NDMF 1.15.1 or later. The tested stable profile uses Unity 2022.3.22f1 and VRChat SDK 3.10.6; other combinations require verification.

This source candidate has no published Release archive or active VPM package version yet.
